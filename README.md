# Lunar Outpost

Lunar Outpost is a lunar base management game made for the **NASA Space Apps Challenge**. You run a small Moon outpost: keep the crew alive, manage oxygen, water, food, energy, materials and budget, build and repair modules, research technology, and complete a yearly mission.

## Play online

**https://unijacobo-lang.github.io/Astronaut-trainer/**

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech

Vanilla JavaScript, Vite and Canvas 2D. No runtime dependencies.
